# AGENTS.md

Instructions for AI coding agents working in the `cardx` R package.

Human-facing contributor documentation lives in
[`.github/CONTRIBUTING.md`](https://pharmaverse.github.io/cardx/CONTRIBUTING.md).
This file is the condensed, directive version. Where they overlap, they
should agree — if you change a convention, change both.

## What this package is

`cardx` extends [`cards`](https://github.com/pharmaverse/cards) with
*extra* Analysis Results Data (ARD) functions. `cards` owns the
framework: the `card` class, the tidiers, the structural checks, and the
example datasets. `cardx` owns the wrappers: each exported function runs
one statistical method from another package (`stats`, `survival`,
`survey`, `car`, `emmeans`, `aod`, `smd`, `effectsize`) and returns the
result as an ARD.

Consequence: **almost nothing here is novel code.** Every function is a
variation on the same skeleton. Before writing a new one, read the
closest existing analogue and copy its shape. Do not invent a new
structure.

Canonical exemplars, in order of increasing complexity:

| File | Pattern |
|----|----|
| [`R/ard_stats_chisq_test.R`](https://pharmaverse.github.io/cardx/R/ard_stats_chisq_test.R) | Simplest complete wrapper. The default template. |
| [`R/ard_stats_t_test.R`](https://pharmaverse.github.io/cardx/R/ard_stats_t_test.R) | Two exports sharing one help page via `@rdname`; shared `.format_*()` internal helper. |
| [`R/ard_car_vif.R`](https://pharmaverse.github.io/cardx/R/ard_car_vif.R) | No upstream `broom` tidier — pivot to ARD shape by hand. |

## Never edit these by hand

| Path | Why / what to do instead |
|----|----|
| `R/import-standalone-*.R` | Vendored copies. Refresh with `usethis::use_standalone("insightsengineering/standalone", "<name>")`. |
| `NAMESPACE` | Generated by roxygen2. Run [`devtools::document()`](https://devtools.r-lib.org/reference/document.html). |
| `man/*.Rd` | Generated by roxygen2. Edit the roxygen block in `R/`, then [`devtools::document()`](https://devtools.r-lib.org/reference/document.html). |
| `tests/testthat/_snaps/*.md` | Generated by testthat. Run [`testthat::snapshot_accept()`](https://testthat.r-lib.org/reference/snapshot_accept.html) after verifying the diff with [`testthat::snapshot_review()`](https://testthat.r-lib.org/reference/snapshot_accept.html). |

If a change appears to require editing a standalone file, stop and say
so rather than editing it.

## Non-negotiable conventions

Checklist for any new or modified exported function:

File is `R/<function_name>.R`, named exactly after the function.
Function is named `ard_<package>_<function>()`.

**`set_cli_abort_call()` is the first line of the function body.** No
exceptions.

`check_pkg_installed("<pkg>")` before touching anything from `Suggests`.
Vector form for several:
`check_pkg_installed(c("car", "broom.helpers"))`.

Arguments validated with `check_not_missing()`, then
`check_data_frame()` / `check_class()`, then
`cards::process_selectors(data, by = {{ by }}, ...)`, then
post-resolution checks (`check_scalar()`, `check_range()`).

Empty-selection short circuit:
`if (is_empty(variables)) return(dplyr::tibble() |> cards::as_card(check = FALSE))`.

**Every statistical call is wrapped in
[`cards::eval_capture_conditions()`](https://pharmaverse.github.io/cards/latest-tag/reference/eval_capture_conditions.html).**
Errors and warnings belong in the ARD’s `error`/`warning` columns, never
propagated. Data reshaping that could fail goes *inside* the same block.

Class applied with `cards::as_card(check = FALSE)`. **Never**
`structure(..., class = "card")` or `class(x) <- "card"`.

Columns ordered with
[`cards::tidy_ard_column_order()`](https://pharmaverse.github.io/cards/latest-tag/reference/tidy_ard_order.html)
(plus
[`cards::tidy_ard_row_order()`](https://pharmaverse.github.io/cards/latest-tag/reference/tidy_ard_order.html)
where relevant).

Own errors raised as
`cli::cli_abort("msg", call = get_cli_abort_call())`.

Argument order: `data`, `variables`, `by`, function-specific args,
`...`.

Native pipe `|>`, two-space indent. Do not introduce `%>%` in package
code.

Internal helpers are dot-prefixed, in the same file, with
`@keywords internal`.

## The ARD contract

Column set and order:

    group1, group1_level, [group2, group2_level, ...],
    variable, variable_level,
    context, stat_name, stat_label, stat, fmt_fun, warning, error

`stat`, `fmt_fun`, `warning`, and `error` are **list-columns**.

- `context` is the function name minus the `ard_` prefix, snake case.
  [`ard_car_vif()`](https://pharmaverse.github.io/cardx/reference/ard_car_vif.md)
  → `"car_vif"`.
- The formatting column is **`fmt_fun`**. `fmt_fn` is deprecated; it
  exists only as a soft-deprecated *argument* in two survey methods. Do
  not write `fmt_fn` in new code.
- Populate `stat_label` with human-readable labels — via a
  `.df_*_stat_labels()`
  [`dplyr::tribble()`](https://tibble.tidyverse.org/reference/tribble.html)
  left-joined on `stat_name` and finished with
  `dplyr::coalesce(stat_label, stat_name)`, or an inline
  [`dplyr::case_when()`](https://dplyr.tidyverse.org/reference/case-and-replace-when.html)
  for a short list.

Validate the result with
[`cards::check_ard_structure()`](https://pharmaverse.github.io/cards/latest-tag/reference/check_ard_structure.html);
it must run silently.

## Use the internal vocabulary — do not add dependencies

Hard `Imports` are exactly: `cards`, `cli`, `dplyr`, `glue`,
`lifecycle`, `rlang`, `tidyr`. **Do not add to `Imports`.** A
statistical package goes in `Suggests` with a minimum version and is
called as `pkg::fun()`.

Much of `purrr`, `stringr`, `forcats`, and `tibble` is already vendored
and callable **unqualified**. Do not reach for the namespaced version,
and do not add these packages as dependencies:

| File | Provides (call these bare) |
|----|----|
| `R/import-standalone-purrr.R` | `map()`, `map_chr()`, `map_lgl()`, `map2()`, `imap()`, `pmap()`, `keep()`, `discard()`, `compact()`, `reduce()`, `transpose()` |
| `R/import-standalone-stringr.R` | `str_detect()`, `str_replace()`, `str_replace_all()`, `str_remove()`, `str_extract()`, `str_trim()`, `str_squish()`, `str_split()`, `str_pad()`, `word()` |
| `R/import-standalone-forcats.R` | `fct_relevel()`, `fct_collapse()`, `fct_inorder()`, `fct_infreq()`, `fct_rev()`, `fct_expand()`, `fct_na_value_to_level()` |
| `R/import-standalone-tibble.R` | `deframe()`, `enframe()`, `remove_rownames()`, `rownames_to_column()` |
| `R/import-standalone-checks.R` | `check_not_missing()`, `check_data_frame()`, `check_class()`, `check_scalar()`, `check_string()`, `check_logical()`, `check_range()`, `check_integerish()`, `check_n_levels()`, `check_binary()`, … |
| `R/import-standalone-check_pkg_installed.R` | `check_pkg_installed()`, `is_pkg_installed()`, `skip_if_pkg_not_installed()` |

## Documentation

- Every `@param` opens with a parenthesized type, then `\cr`, then an
  indented description: `` (`data.frame`)\cr ``,
  `` (scalar `numeric`)\cr ``,
  `` ([`tidy-select`][dplyr::dplyr_tidy_select])\cr ``.

- `@return` for new functions is `an ARD data frame of class 'card'`.
  Older files often say just `ARD data frame`; use the fuller wording in
  new code, and do not “fix” existing ones as a drive-by.

- `@family` is not used in this package. Grouping is done in
  `_pkgdown.yml`.

- **Examples needing a suggested package must be guarded**, listing
  every suggested package the example touches:

  `#' @examplesIf cardx:::is_pkg_installed("broom")`` ``#' @examplesIf cardx:::is_pkg_installed(c("survival", "broom", "ggsurvfit"))`

  Use
  [`cards::ADSL`](https://pharmaverse.github.io/cards/latest-tag/reference/adam.html)
  / `ADTTE` / `ADLB` / `ADAE` as example data. Unguarded `@examples`
  only when the example needs nothing beyond `Imports`.

## Tests

- `tests/testthat/test-<function_name>.R`, mirroring `R/` one-to-one.
- `skip_if_pkg_not_installed(c("broom", ...))` on **line 1, outside any
  `test_that()`** — not
  [`testthat::skip_if_not_installed()`](https://testthat.r-lib.org/reference/skip.html).
  Include `withr` when the file uses
  [`withr::local_options()`](https://withr.r-lib.org/reference/with_options.html).
- `tests/testthat.R` runs `test_check("cardx", stop_on_warning = TRUE)`,
  so **any unexpected warning fails the suite**.
- Four tests are expected for a new ARD function:
  1.  Correctness vs. the wrapped function, via
      `cards::get_ard_statistics(...)` compared with the raw call,
      `ignore_attr = TRUE`.
  2.  Additivity — `variables = c(A, B)` equals
      [`dplyr::bind_rows()`](https://dplyr.tidyverse.org/reference/bind_rows.html)
      of the single-variable results.
  3.  Failures land in the `error`/`warning` column instead of aborting.
  4.  Last test in the file:
      `test_that("fn() follows ard structure", ...)` with
      `expect_silent(... |> cards::check_ard_structure())`. Pass
      `method = FALSE` if the ARD has no `method` statistic.
- Snapshots: `expect_snapshot(x |> as.data.frame())`, and
  `withr::local_options(list(width = 250))` at the top for wide ARDs.
- Target 100% coverage on new code.

## Easily forgotten steps

These are the four things most often missed. Check all of them before
reporting done:

1.  **`_pkgdown.yml`** — add the new topic under the matching
    `subtitle: "{pkg} package"`. The pkgdown build fails on a documented
    topic missing from the reference index.
2.  **[`devtools::document()`](https://devtools.r-lib.org/reference/document.html),
    then commit `man/` and `NAMESPACE`.** CI runs `roxygen` with
    `auto-update: false` and fails on stale generated docs.
3.  **`inst/WORDLIST`** — add any new jargon; the CI `spelling` job
    checks against it.
4.  **`NEWS.md`** — a bullet under `# cardx (development version)`:
    complete sentence, past tense, backticked function names with
    trailing `()`, issue/PR number in parentheses at the end,
    e.g. `(#310, @handle)`.

## Verification

`styler``::`[`style_pkg`](https://styler.r-lib.org/reference/style_pkg.html)`(``)`` ``devtools``::`[`document`](https://devtools.r-lib.org/reference/document.html)`(``)`` ``devtools``::`[`test`](https://devtools.r-lib.org/reference/test.html)`(``)`` ``spelling``::`[`spell_check_package`](https://docs.ropensci.org/spelling//reference/spell_check_package.html)`(``)`` ``devtools``::`[`check`](https://devtools.r-lib.org/reference/check.html)`(``)`

[`devtools::check()`](https://devtools.r-lib.org/reference/check.html)
is the real gate — it runs examples, so a missing or wrong `@examplesIf`
guard surfaces there and nowhere else. Do not report a change as
verified on the strength of
[`devtools::test()`](https://devtools.r-lib.org/reference/test.html)
alone.

## What CI enforces

| Job | Fails when |
|----|----|
| `roxygen` (`auto-update: false`) | `man/` or `NAMESPACE` is stale relative to the roxygen comments |
| `style` (`auto-update: false`) | [`styler::style_pkg()`](https://styler.r-lib.org/reference/style_pkg.html) would change a file |
| `R-CMD-check` | Standard check on macOS/Windows/Ubuntu across R devel, release, oldrel-1 |
| `R-CMD-check-oldrel` | Check on oldrel-2/-3 with **only hard dependencies installed** — this is what the `check_pkg_installed()` / `@examplesIf` / `skip_if_pkg_not_installed()` guards exist for |
| `spelling` | A word is absent from `inst/WORDLIST` |
| `coverage` | Coverage regresses |
| `docs` (pkgdown) | A documented topic is missing from `_pkgdown.yml` |

## Git

- Branch from `main` as `<issue_id>_<short_description>`,
  e.g. `420_fix_vif_backticks`.
- Never commit directly to `main`.
- Merge via “Squash and merge” or “Rebase and merge”.
- Do not commit or push unless explicitly asked.
